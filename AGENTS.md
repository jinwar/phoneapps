# Repository workflow

The owner is the sole maintainer of this repository and requests that future changes be committed directly to `main`. Do not create a feature branch or pull request unless the owner explicitly requests one. Always select `main` explicitly rather than assuming the repository's default branch is `main`.

Before editing, fetch `origin`, explicitly switch to `main`, and fast-forward it to `origin/main`. The remote default branch may point to an older app branch; do not use it as the starting point. Commit and push completed changes directly to `main`.
